# mistral-personality-chatbot
🤖 PersonaAI

A Multi-Personality AI Chatbot powered by Mistral AI and LangChain.

Interact with an AI assistant that can switch between different personalities:
😆 Funny
😡 Angry
😔 Sad

Built using Streamlit, LangChain, and Mistral AI to demonstrate conversational AI, prompt engineering, session memory, and dynamic personality-based interactions.
